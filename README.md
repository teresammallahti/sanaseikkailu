# Sanaseikkailu

Selainpohjainen sanastonharjoittelu 4. luokan englantiin (10-vuotiaalle). Sovellus kysyy sanan satunnaisesti joko englanniksi tai suomeksi, ja vastauksen voi antaa näppäimistöllä, kynällä tai puhumalla.

## Rakenne

- `index.html` — koko sovellus yhdessä tiedostossa. Sanasto on upotettu tiedostoon, joten sovellus toimii myös ilman palvelinta.
- `sanasto/en_4lk_v2.json` — sanasto: 194 sanaa, 22 teemaa.
- `sanasto/pops_ehdotukset.md` — POPS-tarkistuksen muistiinpanot.

## Tila

Vaiheet 1–4 valmiit: käyttöliittymä, sanasto, ydinlogiikka ja edistymisen tallennus (IndexedDB). Seuraavaksi vaihe 5: käsinkirjoitus- ja puheentunnistus.

## Sanaston lähteet

Sanasto on koottu itsenäisesti 4. luokan englannin aihepiirien pohjalta ja täydennetty POPS 2014:n (Englanti A-oppimäärä, vuosiluokat 3–6) aihepiirien mukaan. Oppikirjan kuvia tai tekstiä ei ole käytetty.
